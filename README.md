# 🏏 IPL Win Probability Predictor

This project predicts the **win probability of IPL teams** in real-time using historical data and match conditions. Built with Python and Jupyter Notebook, it showcases data science and machine learning skills applied to a real-world sports scenario.

---

## 📌 Features

- **Live match inputs**: Team names, score, overs, wickets, and more.
- **Win probability predictions**: Based on current match stats.
- **Interactive visualization** (if applicable).
- **Model training & evaluation** included in the notebook.

---

## 🛠️ Tech Stack

- **Python 3.x**
- **Pandas** – data manipulation
- **NumPy** – numerical computations
- **Matplotlib / Seaborn** – data visualization
- **Scikit-learn** – machine learning modeling
- **Jupyter Notebook** – interactive development
